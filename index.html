Cloudflare OHTTP gateway

核心摘要 (Core Insight)

Cloudflare 宣佈推出 OHTTP gateway 服務，這是一種基於 Oblivious HTTP (OHTTP) 標準的新型隱私保護技術。它旨在通過在客戶端和伺服器之間引入一個中介，分離 IP 位址和應用層請求，從而提高網路請求的匿名性與隱私性，使得內容提供者無法直接知道請求來源。

關鍵要點 (Key Takeaways)

  • 導入 Oblivious HTTP (OHTTP) 標準，增強網路隱私保護。
  • 實現 IP 位址與請求內容的解耦，提高用戶匿名性。
