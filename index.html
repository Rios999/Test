When str.lower() is a security vulnerability in Python – Seth Larson

核心摘要

文章揭示了 Python 的 `str.lower()` 方法在特定情況下可能引發安全漏洞，尤其是在處理 Unicode 字串和不同語言環境 (locales) 時。

這表明看似簡單的字串操作可能隱藏著複雜的跨語言安全風險，對開發者是個重要提醒。

關鍵要點

  • Locale 敏感性：`str.lower()` 的行為可能受執行環境的 locale 設定影響，導致結果不一致。
  • Unicode 複雜性：特定 Unicode 字元的大小寫轉換規則在不同上下文可能有所不同，產生非預期的字串。
  • 安全風險：在需要嚴格字串匹配或規範化的安全敏感場景，這種不一致可能被利用來繞過驗證或過濾。

社群觀點與連結
